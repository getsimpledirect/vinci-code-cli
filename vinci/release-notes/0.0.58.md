Vinci Code 0.0.58 improves sign-in, offline startup and image editing, and updates affected dependencies.

**Open sign-in links from the keyboard.** Press Enter to open the displayed sign-in link. Manual code entry and cancellation remain available. Unsupported links and terminal control characters are rejected before rendering or opening. Fullscreen guidance explains the terminal gesture for your platform.

**Offline startup stays offline.** Offline and bounded QA modes block automatic updater requests and fd/ripgrep downloads, including lazy and helper paths. Existing tools on PATH and cached tools remain available.

**Remove an unsent image in one step.** One Backspace removes the image attachment without deleting adjacent text; Undo restores it. Scrolling and overlay focus preserve keyboard navigation.

**Clearer model and account guidance.** Sign-in and model selection explain the next action when an account or model is missing. Other providers remain available through /other.

**Updated dependencies.** This release includes reviewed Undici, Forge and sandbox-runtime dependency repairs and development-tool security updates.
