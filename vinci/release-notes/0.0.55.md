This release keeps verification results honest when a verifier fails, keeps prompts with images intact, and adds a local task client.

**A failed verification no longer replaces a verdict.** When a remote verification pass fails or is cancelled, Vinci now records it as an attempt rather than as a verdict. An attempt cannot overwrite a verdict that was already issued, and a failed verifier no longer turns the task outcome into `DONE_UNVERIFIED`; the receipt reports the local outcome instead. Only a pass, a block, or a conditional result counts as a verdict.

**Prompts that attach an image keep their formatting.** Attaching an image by path used to collapse every run of whitespace in the whole prompt, which flattened pasted code and lists into one line. Now newlines and indentation are kept, and only the spaces next to the image reference are tidied.

**`vinci runtime` is a client for a local task listener.** It can create, inspect, watch, answer, approve, correct, and cancel tasks on a listener that you point it at with `VINCI_RUNTIME_CONFIG`. It works only with a listener you configure explicitly and launches no worker. The listener is currently a local qualification fixture, not a deployed service. See `vinci/docs/environment.md`.

**Releases now prove that the packaged CLI starts.** Before anything is published, the release pipeline unpacks the exact archive that ships and runs the real launcher offline, with every extension and the agent loop, against a local stand-in for the Vinci service. It also checks that the archive never loads a private package at runtime.
