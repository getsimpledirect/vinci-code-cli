Two fixes, both about the client telling you the truth about itself.

**A guard-blocked run no longer reports as a read-only success.** When the command guard stopped a destructive shell command, the outcome record still said the task was `DONE` and described it as "the requested read-only task completed without project changes". The run had accomplished nothing. Blocked bash calls now register as an attempted change that did not go through.

**The receipt no longer claims Vinci billed a turn it did not.** Every receipt ended with "Billed total in Platform." — including turns run entirely on your own provider key, where the credential never reaches us and neither does the charge. The line now follows the provider that actually served the turn, and says nothing at all when no provider was recorded.

**The header no longer says "signed in" after you sign out.** `/logout` removed the credential while the header and the composer badge went on reporting a connection, directly above the authentication picker. That badge is how you tell a managed turn from one on your own key, so a stale one is worse than none.

**The installer refuses a `VINCI_BIN_DIR` inside `VINCI_HOME`.** That combination made the launcher a symlink to itself, and every later `vinci` call failed with "too many levels of symbolic links" — an error naming neither path. The defaults never collide; only an explicit override reached it.

Also in this release: the repository is public at [github.com/getsimpledirect/vinci-code-cli](https://github.com/getsimpledirect/vinci-code-cli) under MIT, and the documentation now describes bring-your-own-key as the default rather than an option.
