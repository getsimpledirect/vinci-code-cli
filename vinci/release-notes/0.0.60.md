Vinci Code 0.0.60 fixes an exit code that 0.0.59 got wrong, and updates two dependencies.

**Scripts: a successful run exits 0 again.** In 0.0.59, a print (-p) or JSON run could exit with code 3 after the requested change was made: if Vinci first tried to write a file through the shell, was redirected to its file editor, and then used the editor successfully, the run was still saved as blocked. That run now finishes normally and exits 0. A shell write that is refused and not followed by a successful edit still exits 3.

**Dependency updates.** Vinci no longer includes fast-xml-parser, which had a low-severity advisory, and the node-forge copy used only by the optional Gondolin example extension is updated to 1.4.3. Neither issue was reachable in normal use.
