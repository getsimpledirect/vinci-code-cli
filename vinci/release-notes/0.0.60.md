Vinci Code 0.0.60 fixes an exit code that 0.0.59 got wrong, and takes upstream security fixes for two dependencies.

**Scripts: a successful run exits 0 again.** In 0.0.59, a print (-p) or JSON run could exit with code 3 even though the requested change was made: if Vinci first tried to write a file through the shell, was redirected to its file editor, and then made the change there, the run was still saved as blocked. That run now finishes normally and exits 0. A write that is refused and never made still exits 3.

**Dependency security updates.** The AWS XML component no longer pulls in fast-xml-parser, so GHSA-474x-hrwr-fgx4 no longer applies. The node-forge copy used only by the optional Gondolin example extension is updated to 1.4.3.
